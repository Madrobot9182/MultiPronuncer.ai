# MultiPronuncer.ai

https://multi-pronuncer-ai.vercel.app/
A modern translation and pronunciation service powered by Microsoft Azure Speech. Learn and practice a wide range of languages with a fast and easy to use interface.

## Pronunciation Practicer

Read some text aloud and let the AI analyze your performace based on various factors. Visualized in a easy to use interface with many languages supported:

- Accuracy: Precision of word spoken

- Fluency: How naturally and smoothly you spoke

- Completeness: How much of the text you pronunced

- Prosody (en-us only): How well your rhythm and intonation matches the language.

## Translator

A simple translation service with as many languages as Azure supports. Convenient features like auto detection built in.
